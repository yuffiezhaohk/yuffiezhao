# **DeepHalo and Sparse Shocks: Replication of Discrete Choice Models**


## 📂 Root Directory Content  

### Files & Folders  
| Name                      | Type       | Description                                  |  
|---------------------------|------------|----------------------------------------------|  
| `part1/`                   | Folder     | **DeepHalo Replication:** A replication of the **featureless** DeepHalo model introduced by Zhang et al. (2025), focusing on neural network-based Discrete Choice Models (DCM) and RMSE performance.|  
| `part2/`                   | Folder     | **Sparse Shocks:** An replication of Lu and Shimizu (2025), implementing a different econometric approach to choice modeling, specifically focusing on sparse shocks and shrinkage estimators.|  
| `environment.yml`              | File       | Project’s runtime dependencies (Python version, packages, etc.)|
